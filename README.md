# ขอเพลง

หลังบ้านที่ `/` (หน้าแรก) · จอใหญ่ QR+คิว+วิดีโอที่ `/screen` · มือถือที่ `/remote`

จอใหญ่: แถบซ้ายแนวตั้งเป็น QR + คิวเพลง, ขวาเป็นกล่องวิดีโอ 16:9, แชทจากมือถือจะลอยทับวิดีโอวิ่งจากขวาไปซ้าย (ปุ่ม ⛶ เต็มจอ อยู่มุมขวาบนของวิดีโอ)

- ไม่มีคิว → แสดงหน้า "คิวว่าง" (ไม่สุ่มเพลงเก่าแล้ว); เปิดหน้าจอแล้วมีคิวจะเล่นเอง ถ้าเบราว์เซอร์บล็อกเสียงอัตโนมัติจะมีปุ่มให้กดเล่น
- หลังบ้าน `/`: ดูเพลงที่กำลังเล่น ข้ามเพลง ลบ/เลื่อนเพลงขึ้นเป็นเพลงถัดไป ล้างคิว และปุ่ม "เปิดหน้าจอ (QR)" เปิดหน้าจอใหญ่ `/screen` เป็นอีกหน้าต่าง
- ตั้งรหัสหลังบ้านด้วยตัวแปร `ADMIN_PASS` (ช่องชื่อผู้ใช้ตอนล็อกอินใส่อะไรก็ได้) ถ้าไม่ตั้ง ใครเปิดหน้าแรกก็เข้าได้ (หน้า `/screen` และ `/remote` ไม่ต้องใส่รหัส)
- ถ้าจอใหญ่เป็นเครื่องเฉพาะ เปิด Chrome ด้วย `--autoplay-policy=no-user-gesture-required` จะเล่นเองได้ทุกครั้งโดยไม่ต้องกดปุ่ม

## รันในเครื่อง
    node server.js

## ขึ้น Render
1. push โฟลเดอร์นี้ขึ้น GitHub
2. Render → New → Web Service → เลือก repo
3. Build Command: (เว้นว่างหรือ `echo ok`)  Start Command: `node server.js`
   Environment: เพิ่ม `ADMIN_PASS` = รหัสหลังบ้านที่ต้องการ
4. เปิด https://ชื่อ.onrender.com (หลังบ้าน) บนคอมที่ต่อจอ แล้วกด "เปิดหน้าจอ (QR)" จากนั้นสแกน QR
